LOCAL CONFIGURATION

连接模型与报告服务

在项目根目录的 .env 中配置，保存后重启网站服务。Key 始终由本机后端读取。

CANCER_MODEL_PATH=outputs/vit_small/<训练目录>/best.pt
CANCER_DECISION_PATH=<可选的 decision.json 路径>
CANCER_DEVICE=auto
DEEPSEEK_API_KEY=<你的真实 Key>
DEEPSEEK_MODEL=deepseek-flash

还没有分类模型？

先准备病理训练数据，再训练 ViT。通用预训练权重不能直接替代病理二分类模型。

python scripts/prepare_data.py --config configs/vit.yaml
python scripts/train.py --config configs/vit.yaml

未配置 decision.json 时使用阈值 0.5。当前支持已裁剪 patch，不支持 WSI、DICOM 或多页 TIFF。
